このサイトを、AWS 上の WordPress から Cloudflare に移しました。サーバー代が毎月かかっていたので、記事はそのまま残して、常時起動のサーバーはやめる方針です。

いまの構成はこうです。

- 記事：Markdown
- サイト：Astro
- 保管：GitHub
- 公開：Cloudflare
- ドメイン：お名前.comのまま

やったことは、この順番です。

1. All-in-One WP Migration でバックアップを取る
2. 記事を Markdown に変換する（URL は `?p=記事ID` → `/posts/記事ID`）
3. 画像も一緒に移す。HTTPS にしないと画像が欠けます
4. GitHub に上げて、Cloudflare で公開する
5. 新しいサイトが独自ドメインで見えてから、AWS の EC2 などを止める

AWS を先に消すとサイトが途切れるので、そこだけ注意です。ドメインはお名前.comに残して、ネームサーバーだけ Cloudflare に変えました。

リポジトリはこちらです。  
https://github.com/kokinnwakashuu/kokinn-com

## 移してから直したこと

公開した直後に、いくつか見た目と広告の問題が出ました。静的サイト化あるある、という感じです。

**自己紹介の飾り枠**  
AFFINGER のショートコードが生テキストで出ていました。見出し枠に変換して直しています。

**サイト名**  
デザインを整える過程で短い名前に見えてしまったので、元のサイト名「自作ゲームの世界を広げることで技術力を高める企画サイト」に戻しました。AdSense やアフィリエイトに紐づく名前は、むやみに変えない方がいいです。

**変な広告**  
「続きへ進むにはこちら」のような全画面広告が出て、関係ないサイトへ飛ぶことがありました。AdSense の自動広告・全画面広告・Multiplex が原因になりやすいです。いまは自動広告オフ、記事下のバナー1枠にしています。

**プロフィール**  
学歴・資格・書籍（76冊）、Kaggle（https://www.kaggle.com/kokinnwakashuu）も、移したタイミングで最新に更新しました。
