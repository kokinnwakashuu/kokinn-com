このサイトを、AWS 上の WordPress から Cloudflare に移しました。サーバー代が毎月かかっていたので、記事はそのまま残して、常時起動のサーバーはやめる方針です。

いまの構成はこうです。

- 記事：Markdown
- サイト：Astro
- 保管：GitHub
- 公開：Cloudflare
- ドメイン：お名前.comのまま

やったことは、この順番です。

1. All-in-One WP Migration でバックアップを取る
2. 記事を Markdown に変換する（URL は `?p=記事ID` → `/posts/記事ID`）
3. 画像も一緒に移す。HTTPS にしないと画像が欠けます
4. GitHub に上げて、Cloudflare で公開する
5. 新しいサイトが独自ドメインで見えてから、AWS の EC2 などを止める

AWS を先に消すとサイトが途切れるので、そこだけ注意です。ドメインはお名前.comに残して、ネームサーバーだけ Cloudflare に変えました。
