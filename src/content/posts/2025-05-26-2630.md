<ul data-start="178" data-end="240">

<p data-start="242" data-end="276">火力の底上げを徹底することで、各ステージを効率よく突破していきます。</p>

<h3 data-start="283" data-end="300">■ 第１ステージ：レイス戦</h3>
<ul data-start="301" data-end="382">
 	<li data-start="301" data-end="336">
<p data-start="303" data-end="336">列攻撃スキルを採用し、<strong data-start="314" data-end="335">初手で一掃可能な火力ラインまで調整</strong>。</p>
</li>
 	<li data-start="337" data-end="382">
<p data-start="339" data-end="382">ダメージリミット近くまでダメージを積んでいるため、<strong data-start="364" data-end="379">ワンターンクリアが可能</strong>です。</p>
</li>
</ul>

<hr data-start="384" data-end="387">

<h3 data-start="389" data-end="409">■ 第２ステージ</h3>
<ul data-start="410" data-end="532">
 	<li data-start="410" data-end="438">
<p data-start="412" data-end="438">雷属性の<strong data-start="416" data-end="424">ディアナ</strong>を使用し、セラを一撃で撃破。</p>
</li>
 	<li data-start="439" data-end="496">
<p data-start="441" data-end="496">さらに、１ターン目最後に<strong data-start="453" data-end="472">リムの攻撃で味方前衛を１体倒す</strong>ことで、次のキャラのスキル発動条件を満たします。</p>
</li>
 	<li data-start="497" data-end="532">
<p data-start="499" data-end="532">これにより、<strong data-start="505" data-end="528">２ターン目のグリフで確実にフィニッシュ</strong>が可能。</p>
</li>
</ul>
<p data-start="534" data-end="580">※補足：バズーカが現環境で<strong data-start="547" data-end="559">最も攻撃力が高い</strong>という情報もあり、火力役として非常に優秀。</p>

<hr data-start="582" data-end="585">

<h3 data-start="587" data-end="611">■ 第３ステージ</h3>

</li>
 	<li data-start="655" data-end="701">

</li>
 	<li data-start="702" data-end="725">
<p data-start="704" data-end="725">最後は強化されたトーブでとどめを刺す流れ。</p>
</li>
</ul>
