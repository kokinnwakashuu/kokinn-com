<h2><strong>ディバインまでの道のり</strong></h2>
Champions Tactics、始めたばかりの頃は攻略情報がほとんどなく、
とにかく手探り状態でした。
<ul>
 	<li>**持っているチャンピオンで戦うも、全然勝てない…**💦</li>
 	<li><strong>フォージしても微妙な性能ばかり…</strong></li>
</ul>
そんな状況から脱するために、たどり着いたのは「観察と研究」！
強いプレイヤーの構成をじっくりメモし、なぜその編成が強いのかを徹底分析しました。
結果、少しずつ勝てるようになり、ついにディバインに到達しました！

<h2><strong>ディバインを目指すための攻略ポイント</strong></h2>
<h3><strong>ステータス基準</strong></h3>
まずは、どのチャンピオンを使うかが重要！
以下のステータスを目安にすると勝率がぐっと上がります👇
<ul>
 	<li><strong>俊敏：20以上</strong></li>
 	<li><strong>攻撃力：20以上</strong></li>
 	<li><strong>体力：70以上</strong></li>
</ul>

<hr>

<h3><strong>チーム編成の基本</strong></h3>
<ol>
 	<li><strong>最初は3体のチャンピオンでOK！</strong>
強い人の構成を参考にしつつ、自分のパーティーを少しずつ強化していきましょう。</li>
 	<li><strong>役割を明確に！</strong>
各チャンピオンに役割を持たせることで、戦術の幅が広がります。</li>
 	<li><strong>マーケットを活用する！</strong>
安くて強いチャンピオンを見つけてフォージでバリエーションを増やすのが鉄則です。</li>
</ol>

<hr>

<h3><strong>ポジション別おすすめチャンピオン</strong></h3>
<h4><strong>1. 前衛（タンク役）</strong></h4>
<ul>
 	<li><strong>おすすめスキル：死者の忍耐</strong>
効果：4ターン経過 or チームの誰かが倒されたときに、敵全体に毒を付与。</li>
 	<li><strong>あるとなおいいおすすめスキル</strong>
<ul>
 	<li>挑発スキル「なんとかカバー」</li>
 	<li>回復スキル「なんとかヴェイル」</li>
</ul>
</li>
 	<li><strong>ジョブとロール</strong>
<ul>
 	<li>ジョブ：パラディン</li>
 	<li>ロール：保護</li>
</ul>
</li>
</ul>
耐久力が高く、相手の攻撃を引き受けられて弱点属性ではないチャンピオンを選びましょう！

<hr>

<h4><strong>2. アタッカーその1（高火力）</strong></h4>
<ul>
 	<li><strong>おすすめスキル：皇帝の祝福</strong>
効果：ダメージを与えると追加で追撃。</li>
 	<li><strong>ステータス目安</strong>
<ul>
 	<li>攻撃力：25以上が理想（属性攻撃スキルが豊富なら20以上でもOK）</li>
</ul>
</li>
 	<li><strong>ジョブとロール</strong>
<ul>
 	<li>ジョブ：自由</li>
 	<li>ロール：ダメージ</li>
</ul>
</li>
</ul>
属性攻撃や相手を強制移動させるスキルを持つキャラを採用すると、戦術に幅が出ます。

<hr>

<h4><strong>3. アタッカーその2（バフ解除＆サポート）</strong></h4>
<ul>
 	<li><strong>おすすめスキル：予知 </strong></li>
 	<li><strong>おすすめスキル　全体バフ解除</strong></li>
 	<li><strong>ジョブとロール</strong>
<ul>
 	<li>ジョブ：Inquisitor</li>
 	<li>ロール：ダメージ</li>
</ul>
</li>
</ul>
高敏捷（敏捷２５以上）による予知と攻撃力（２０以上）が高いキャラを選ぶことで、敵の強化を効率的に無効化できます。

<hr>

<h2><strong>マーケット活用術</strong></h2>
マーケットでのチャンピオン選びは、勝敗を大きく左右します！
初期設定では情報量が多く混乱しますが、<strong>フィルター機能</strong>を活用すれば強いチャンピオンを効率よく探せます。

上記のチャンピオンの情報を参考にしてフィルターするといい感じのチャンピオンが見つかるかも？
<h3><strong>おすすめのフォージ組み合わせ</strong></h3>
<ul>
 	<li><strong>強いアタッカー×強いアタッカー</strong></li>
 	<li><strong>強いタンク×強いタンク</strong></li>
</ul>
これを繰り返すことで、安定して強いチャンピオンを量産できます！
